# 临时通知

[返回组件目录](../README.md) · 反馈 · CSS / HTML

## 目的与边界

确认低风险动作的结果，不能承载唯一的恢复路径。

## 结构

- 简洁结果
- 可选撤销
- 短时出现
- 独立通知区域

## 状态约定

| 状态 | 处理 |
|---|---|
| 默认 | 使用语义主题变量；不由组件硬编码主题颜色 |
| Hover | 仅精细指针启用；颜色与空间变化分开 |
| Focus | focus-visible 清晰且不被容器裁切 |
| Active | 保留标签与上下文；避免修改控件的宽高 |
| Disabled | 仅对交互控件适用；原生 disabled 并说明原因 |
| Loading | 只对异步任务适用；阻止重复请求并标明 busy |
| Error | 在对应上下文提供原因和恢复操作 |
| Empty | 无数据时明确说明原因，不伪造数据 |

## 操作与键盘

使用 polite live region；不自动把键盘焦点拉到 Toast。

## 使用细则

- 常规提示约 4 秒；需要阅读的错误保持在页面。
- 消息更新不重复朗读旧内容。
- 减少动效模式不使用 bounce。

## 主题、密度与布局

采用 `--ds-ink`、`--ds-muted`、`--ds-surface`、`--ds-line` 和对应语义颜色。浅色与深色分别构建，不做全局反相。默认 44px 控件高度；桌面紧凑模式可为 36px，触摸模式为 48px。内容层实底，不添加 backdrop-filter。

## HTML 示例

```html
<button class="ds-button ds-button--secondary" data-toast="已复制示例代码">触发通知</button>
```

该组件提供 HTML/CSS 示例，尚未提供独立 React 封装；业务代码应保留原生语义。

## 验收

- [ ] 关闭通知不会丢失焦点
- [ ] 屏幕阅读器收到一次通知
- [ ] 通知不遮住当前焦点
- [ ] 浅色、深色、200% 缩放和减少动效均可完成任务
- [ ] 错误、禁用和加载状态没有虚构成功结果
