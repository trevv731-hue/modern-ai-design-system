# 数据、图表和真实反馈

## 数据原则

所有实时指标来自同一真实数据源。接口不可用时展示断开、未知或空状态；不能随机生成流量、延迟、命中次数和连接记录。

## 数值显示

字节单位使用 KB/MB，并说明二进制换算；时间、日期和单位采用统一格式。延迟 0 表示未测速时应显示“未测速”，超时单独显示。数值使用 tabular-nums。

## 流量图

曲线颜色对应上传/下载图例。纵轴动态范围跟随数据，不用固定最大值裁掉峰值；曲线之外保留当前数值和采样说明。Canvas 图表需有文本替代和可理解的图例。

窗口大小变化时按 devicePixelRatio 更新画布，避免模糊；不以无限 requestAnimationFrame 绘制没有变化的数据。组件卸载后清理 ResizeObserver、定时器和 WebSocket。

## 表格

金额、流量和延迟等可比較数值右对齐；名称左对齐；协议等短值保持固定宽。排序必须真的改变数据并同步 aria-sort。记录很多时引入分页或虚拟化，并验证读屏和焦点行为。

## 状态过期

接口断开时清理或标记缓存为过期，避免把旧数据继续当实时。连接操作成功后再更新状态。未知数量不编造具体数字；一次请求失败不清空用户已经保存的配置。
