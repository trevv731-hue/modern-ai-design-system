# 国际化和本地格式

## 文本和布局

界面文字保留在应用的语言层，不写入颜色 Token。中文标签短不代表英文标签也短：以扩展 40% 的文案检查工具栏、按钮和标签页。用户节点名称可以含 emoji 和多种文字，应保留原始 Unicode。

## 数据

时间使用用户时区和本地格式；文件名、服务器地址和协议名称保持原文。排序不要依赖英文小写转换作为所有语言的通用排序规则。数字使用 Intl.NumberFormat 时明确是否需要单位和最大精度。

## 凭据和解析

Base64 内容需要按 UTF-8 解码，不能假设 ASCII。分享链接的 percent encoding 正确还原，错误输入不能触发整个界面崩溃。URL token、密码、UUID 不执行自动翻译或大小写修改。

## 方向和输入法

新建 Web 组件尽量使用逻辑属性 inline/block；代码和 URL 区域保持适当的 LTR 表达。中文输入法 composition 期间不把 Enter 当作提交，待输入完成后再响应键盘提交。
