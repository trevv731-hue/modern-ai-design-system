# 验证与交付

## 自动验证

```bash
npm run build
npm test
npm run lint:motion
```

构建生成跨平台 Token、Web 主题、React 源码副本、组件文档和离线目录。验证检查主题完整性、对比度、示例 ID 唯一性、文档链接和禁用动效规则。动效检查报告静态声明，运行时 blur 数量通过浏览器测试确认。

## 浏览器验证

分别检查浅色与深色、舒适与紧凑、宽窗口与窄视口。搜索能过滤组件，Ctrl/Command+K 进入搜索，复制动作有失败回退，标签页方向键可用，dialog 能 Escape 关闭并恢复焦点。

## 应用验证

AetherLink 用真实 Electron 加载打包后的 file 页面。测试页面导航、预加载 IPC、Base64 解析、HTTP 订阅地址导入、直连启停和 REST 通信。订阅下载测试覆盖重定向、HTTP 错误、超时、HTML、空内容及过大内容。

## 手动验证

屏幕阅读器、forced-colors、触摸、200% 字体、慢网速和真实远程节点连通性需要额外检查。普通测试不能替代安全审计、无障碍认证和性能分析。

## 交付清单

- [ ] 代码、规范和实际组件命名一致。
- [ ] 新主题变量从源 JSON 构建，业务没有另一套硬编码配色。
- [ ] 真实功能可运行；未实现功能明确禁用或标明预览。
- [ ] 用户真实订阅和凭据没有进入代码、文档与截图。
- [ ] 提供可打开的入口和清楚的启动方式。
- [ ] 记录实际通过的测试，列出未验证的平台。

## 网关与发布验证（2026-10-17）

适用条件：静态应用通过同源网关访问私有服务或付费 AI。仅在注释中写“图片／请求大小上限”不会限制 request.arrayBuffer() 或 request.text() 的实际内存占用；应逐块统计真实字节，超限取消读取并返回 413。Content-Length 只可辅助提前拒绝，不能替代计数。实际客户端图片的编码膨胀和后端既有上限应一起核对，避免正常功能被拦截。

带服务凭据的请求使用手动重定向策略，拒绝把凭据带到其他地址。通用安全头和私有接口的 no-store 应覆盖错误及授权失败响应；可更新的 HTML 重新验证，内容指纹资产单独缓存。需要定位问题的日志可以保留，但不应持久化敏感查询参数。

发布先核对远端版本及绑定，再验证构建、接口与数据兼容性；保留发布前版本作为回滚依据。部署后分别检查匿名拒绝、授权成功和跨站拒绝，不能以“上传成功”代替功能上线。只读验收不打印凭据或私人响应正文。关闭未使用的预览入口须确认正式域名与内部绑定仍可用，不把单人私有产品的授权策略推广到所有公开产品。

验证记录：本次两个独立站点完成部署，56 项云端测试、22 项服务端及跨站测试、299 项核心前端测试通过；线上授权、匿名及跨站检查通过，原绑定保留。另以独立无头浏览器、显式设备证书和直连条件完成 6 页窄屏冒烟，写入请求全部阻止；默认浏览器连接超时不能独自证明线上故障。未验证边界：独立渗透测试、大规模压力测试和真实手机全流程。

## 离线成果与测试环境分离（2026-10-17）

适用条件：交付离线资源浏览页、逆向分析资料或准备受容量限制的云端归档。模拟器磁盘、系统镜像、内存快照和工具依赖容易掩盖成果的真实大小；将它们放在成果目录外，成果保留提取资源、来源证据和必要分析日志。不要用指向环境目录的联接重新扩大上传范围；迁移前检查进程和外部路径联接，迁移后修正工具路径并核对离线入口的相对资源链接。

本次验证：环境与工具迁移前后逐项核对 1,916 个文件的相对路径和字节长度，334 个保留成果文件 SHA-256 一致，离线查看页 205 个本地引用全部存在。未验证边界：模拟器重启、动态诊断及实际云端上传；文件长度一致不等同于全部环境文件逐字节哈希校验。通用经验是按交付职责拆分并验证依赖；10 GB 上限属于单个产品需求，不作为设计系统的通用容量规则。
