# 文字、错误与隐私

## 常规文字

按钮使用明确动词：“添加订阅”“解析并添加”“停止代理”“恢复设置”。避免“确定”承载多个不明确动作。区域标题使用自然中文；协议名和关键单位保留标准英文。

## 状态用语

| 实际状态 | 推荐 | 避免 |
|---|---|---|
| 请求已发出 | 正在连接 | 已建立安全连接 |
| 内核健康检查成功 | 内核运行中 | 永久稳定运行 |
| 未测速 | 未测速 | 0ms / 随机低延迟 |
| 下载超时 | 下载超时，请稍后重试 | 未能识别格式 |
| 没有节点 | 添加订阅地址开始配置 | 自动添加虚构节点 |
| 未实现 | 尚未支持 | 已开启，但只改变 UI |

## 错误结构

先说明出了什么问题，再给出具体下一步。HTTP 错误可以展示状态码，但不展示带 token 的完整地址。输入错误与输入框相邻，网络错误保持输入值，系统代理恢复失败应说明需要检查 Windows 设置。

## 隐私边界

订阅地址通常包含令牌。不要在日志、异常栈、截图、公开示例和 Git 文件中保存用户真实链接。下载时只发送到用户提供的地址及其重定向目标。不要把该链接发送到搜索引擎或外部转换网站。

导入节点确实会包含凭据；本地持久化必须在产品说明中体现。不要宣称“零泄漏”“绝对安全”等无法验证的保证。产品中的示例节点应明确仅为示例，不能假装已经可连接。

## 长度和信息密度

短成功消息可 Toast；需要处理的错误应在页面保留。较长说明放在帮助区或 details。技术细节只在帮助用户做决定时出现，例如代理端口和被占用的端口。

## 学习型长文与公式说明（2026-10-18）

适用条件：将已有课程、技术 PDF 或研究资料整理成便于自学的长文。问题是读者即使具备先修知识，也可能被省略的推导、不同资料的记号和时间方向卡住；直接扩大摘要长度不能解决这些断点。数学解析器接受公式，也不代表用户实际阅读器能够显示，不能把语法通过作为显示验收的替代。

编排决策：先提供少公式的整体导读，再按原资料主线展开“问题、直觉、定义、推导、例子、自检”；在首次使用处嵌入必要前置知识。对“直接读就能学”的交付，先用可计算的具体例子解释，再逐步推广，不能把证明中的关键步骤留给原 PDF。保留原章节与页码对应，明确区分原资料、补充解释和未核验内容。相近符号及时解释，公式的端点、可积性和数值适用条件就近说明。结尾用卡点索引帮助返回具体段落，避免只给一张公式表。

初学者教程需另外检查教学连续性：标题写成“为什么”或增加例子，仍可能只是知识目录。以一个能先做成的具体任务贯穿，先让读者看见现有办法的缺口，再引入填补缺口的新工具；每节明确继承、任务、动作、得到的结果和下一处缺口。前置知识在任务需要时加入，不能让读者一开始先穿过整套定义。练习直接检查本节刚做的动作，答案指出具体错误与回查位置，不使用“是否听懂”代替理解证据。

显示决策：对阅读器兼容性不稳定的数学长文，提供固定排版 PDF，并保留可编辑源稿；离线 HTML 如需提供，应预排公式并打包字体和图像。检查真正导出的页面、长公式宽度、定义与公式的分页、表格和代码，不只检查渲染前源文件。公式保留为清晰字体排版，避免把整篇文字栅格化。

验证记录：教学重构版保留 22 节连续任务及对应练习，487 处数学表达式通过 KaTeX 解析，参数换算、可解模型、后验权重、离散速率与噪声方差积分通过数值核对。运行一维 NumPy 生成实验，固定种子下完成 4500 次训练与 4096 个新样本采样，图示来自真实输出而非示意伪造；这仅验证一次配置可运行。最终 PDF 49 页，检查全部页面缩略图及关键教学、公式和代码的放大页面；未发现页边越界、未替换占位符或孤立的极短尾页。未验证边界：任意第三方 Markdown 阅读器、所有 PDF 阅读软件、其他随机种子、真实图像训练与读者学习成效；可运行、排版正确和语法通过都不等于形式化证明或教学效果认证。

通用原则是按理解依赖分层、保留来源定位、区分数学对象并验证实际阅读产物。本次用户选择 PDF 主阅读、Markdown 留源，原 PDF 保留；不将这一格式偏好推广为所有产品规则。本次仅更新文案指南，未修改组件或 Token 源码。
