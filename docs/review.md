# 设计评审清单

## 任务和信息

- 用户进入页面后是否知道能做什么？
- 每个区域是否只有一个清晰的主动作？
- 标题、说明和数据是否与真实业务状态一致？
- 是否把未实现功能标为已启用？

## 视觉

- 内容层是否实底，导航层是否最多两处可见模糊？
- 颜色是否引用语义变量，暗色状态是否单独检查？
- 主次文字、间距和分组能否在灰度下成立？
- 是否删除无意义的持续呼吸、闪烁和 bounce？

## 行为

- 待处理状态是否防止重复提交？
- 失败是否保留输入并提供可执行恢复？
- 快速切换、页面离开、内核退出是否正确清理？
- 空状态是否区分首次使用和筛选无结果？

## 无障碍

- 所有主要任务能否只用键盘完成？
- label、名称、aria 状态和焦点顺序是否正确？
- 缩放、高对比、减少动效下是否仍可操作？
- 是否只靠颜色、图标或动效传达信息？

## 交付

- 文档有没有准确列出实现与未实现范围？
- 测试是否验证行为，而不只重复实现细节？
- 截图和日志有没有用户凭据？
- 可打开入口和构建命令是否实际运行过？
