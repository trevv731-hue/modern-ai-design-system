# 场景：设置和权限

## 分组

按照用户任务分为网络、系统集成、外观和关于，不按照源代码模块命名。设置标题解释作用，帮助文字说明什么时候生效。危险设置要说明影响。

## 立即生效与保存生效

主题和密度可以立即生效。需要重启连接的端口在连接期间禁用，帮助文字说明断开后可修改。多字段事务使用显式保存按钮；不要让一个表单混合两种生效方式却没有说明。

## 验证

端口必须整数 1–65535，控制器和代理端口不同；错误出现在字段附近，输入值保留。开关依赖后端确认时显示 pending，失败回到原状态。

## 未实现功能

开机自启动、TUN 或静默启动未实现时禁用，旁边显示“尚未支持”。不能只改变 checkbox 并提示“已开启”。如果只是概念预览，整块区域明确标明未生效。

## 权限

请求权限前说明真实功能和必要性，拒绝后提供替代路径。不要在阅读设置或打开页面时自动执行外部修改。

## 私人数据的设备授权与恢复

问题：仅提供软件令牌入口会使浏览器无法直接查看；只加设备凭证又可能在换机后锁住本人。适用于单人私人数据工作区的决策是：日常设备授权、独立备用恢复、管理端重置分开设计。恢复入口应在未授权状态可找到；管理权限是重新签发凭证的依据，不代表浏览器能自动识别网站拥有者。设备凭证过期、恢复会话到期、撤销与换机各自说明下一步。共享电脑上的免提示访问必须明确其 Windows 用户/浏览器使用边界。

软件同步凭证与站长凭证分开；旧客户端新增认证时，同时提供配对与失败提示。本机保存、等待上传、服务端确认三种状态不能混写。密钥不放在网址、静态资源、公开源码或维护文档中，维护代理不保留独立后门。保护需覆盖页面、数据接口及备用域名；私人数据渲染仍需防止脚本注入。

验证记录（2026-10-16）：已验证本机证书和恢复会话可读取、匿名和其他来源的请求被拒绝、证书撤销/错误指纹和会话篡改/过期测试、应用令牌隔离、配对验证失败不保存、旧客户端未配对保留本机数据。设备证书优先是本次单产品选择，不作为所有产品的默认登录方式。未验证边界：浏览器完全无提示、其他浏览器/操作系统的证书选择，以及真实丢机后的完整管理端恢复演练；系统策略写入失败时不能显示“自动进入已配置”。本次专题构建通过，设计系统完整测试在既有组件数量校验处失败（实际 81、预期 75），未改写该计数来掩盖问题。

## 关于

显示真实版本和已验证能力。内核版本从 API 获取，无法获取时显示未知；不填固定的旧版本和随机内存数据。帮助链接和退出托盘说明应可找到。
