# 场景：设置和权限

## 分组

按照用户任务分为网络、系统集成、外观和关于，不按照源代码模块命名。设置标题解释作用，帮助文字说明什么时候生效。危险设置要说明影响。

## 立即生效与保存生效

主题和密度可以立即生效。需要重启连接的端口在连接期间禁用，帮助文字说明断开后可修改。多字段事务使用显式保存按钮；不要让一个表单混合两种生效方式却没有说明。

## 验证

端口必须整数 1–65535，控制器和代理端口不同；错误出现在字段附近，输入值保留。开关依赖后端确认时显示 pending，失败回到原状态。

## 未实现功能

开机自启动、TUN 或静默启动未实现时禁用，旁边显示“尚未支持”。不能只改变 checkbox 并提示“已开启”。如果只是概念预览，整块区域明确标明未生效。

## 权限

请求权限前说明真实功能和必要性，拒绝后提供替代路径。不要在阅读设置或打开页面时自动执行外部修改。

## 关于

显示真实版本和已验证能力。内核版本从 API 获取，无法获取时显示未知；不填固定的旧版本和随机内存数据。帮助链接和退出托盘说明应可找到。
