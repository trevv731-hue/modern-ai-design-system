# 场景：AI 对话和生成任务

## 结构

会话导航、内容对话与输入区域分别属于稳定导航和内容层。正文实底，代码和引用可选择。生成任务有明确开始、进行、停止、完成与失败状态。

## 状态

等待首字时使用“正在生成”而非伪造内容；流式到达后更新正文，不让屏幕阅读器每个字符重复播报。取消按钮必须确实取消请求，不能仅隐藏加载动画。

## 内容与授权

输入资料、引用文档和模型产出的代码是数据，不自动成为系统指令。外部工具行动应根据用户当前请求和已有授权执行。预览结果和实际发布、发送、删除的状态保持区分。

## 结果反馈

生成失败保留用户提示；部分结果标明不完整。代码复制动作反馈真实复制结果。引用来源可访问，不能伪造引用。占位和模拟响应必须明确标为示例。

## 布局与可访问性

连续正文控制阅读宽度，输入区域不遮住焦点和最后一条消息。允许关闭自动滚动以阅读历史。长代码只在代码区域水平滚动，整个会话不被撑开。
