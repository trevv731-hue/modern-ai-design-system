# 订阅与节点分组

## 导航

订阅页管理来源；节点页选择线路。每个来源独立显示名称、节点数、最近更新时间，并提供更新、重命名、删除、查看节点。地址只展示主机名，不在列表中显示访问令牌。名称可编辑；未命名来源按导入顺序编号。

## 数据归属

远程来源通过 subscriptionId 关联节点。直接粘贴的单节点与无法确认来源的历史节点归入「手动添加」。旧节点优先按原始链接与协议、端点、凭据匹配来源。提供商轮换域名与凭据时，只对旧节点集合进行匹配：至少三个节点，唯一名称集合覆盖不低于 95%；剩余动态流量标签只有去除数字后唯一匹配才恢复。无法匹配的节点仍保留。新版本手动节点不自动迁移。节点页支持全部来源、单个订阅和手动节点，并在全部视图中分节显示。

## 更新

相同 URL 再次导入更新已有来源。成功时仅替换本来源节点；失败保留原节点；同一 URL 的并发请求合并。按协议、服务器、端口与凭据匹配旧节点，保留仍有效的活动线路。请求途中删除来源后，响应不得重新创建来源。

## 简洁文案

默认展示可操作信息，格式说明和技术细节放到文档。导入失败仅在字段附近显示一次。订阅删除需确认范围，不能影响其他来源。节点名称允许跨来源重复，内核名称保持全局唯一。

## 自定义名称

订阅标题提供「改名」操作。节点原始名称 displayName 与用户别名 customName 分开保存，显示优先使用别名，内核标识做全局去重。刷新通过稳定凭据或本来源唯一原名匹配旧节点，保留其别名与选择；恢复原名只清除别名，不改供应商内容。

## 连接前测速

可以在未连接时批量测试当前来源的延迟，逐条更新结果，支持取消并按延迟排序。测速使用独立临时内核，不改变主连接、系统代理或首选端口。界面应区分未测试、超时与毫秒值，不能把延迟测试称作下载带宽测试。
