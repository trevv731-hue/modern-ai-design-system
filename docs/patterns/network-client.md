# 场景：连接客户端与订阅导入

## 页面组合

标题栏显示产品名称、实际内核状态和端口；侧栏提供仪表盘、节点、规则、连接和设置。仪表盘首先回答“是否连接”和“使用哪个节点”，其次展示实际流量，最后提供订阅导入。

## 订阅任务

```text
粘贴地址/内容 → 校验 → 下载（仅 HTTP/HTTPS）→ 解析 → 保存 → 节点列表
                    失败 ───────────→ 保留输入 + 明确原因 + 重试
```

输入框同时接受分享 URI、Base64、多行 URI 和 Clash YAML。HTTP/HTTPS 地址由桌面主进程下载，避免浏览器跨域限制。下载按钮显示 busy 并禁用重复点击；下载失败和解析失败分开说明。

## 成功反馈

展示实际导入数量。没有有效节点时不清空已有数据。名称重复自动区分，活动节点选择保持稳定。地址及节点凭据不写日志。测试使用隔离用户数据，真实订阅不作为公开 fixture。

## 连接任务

先校验配置、确认代理和控制器端口、启动内核并等待健康检查；按用户设置启用系统代理；完成后显示运行中。失败清理内核并恢复系统代理。界面不能提前显示已连接。

## 异常和退出

主窗口关闭至托盘必须可恢复；安全退出要停止内核并恢复原设置。任务管理器强制结束不能保证退出回调执行，因此说明下次启动恢复行为，而不承诺所有崩溃都立即恢复。

## 验收

真实地址能下载并解析；HTTP 错误、空内容、HTML 和超时能提示；未连接模式不显示虚构流量；没有节点时说明需要导入；直连模式可以独立测试内核；修改主题不重启内核。
