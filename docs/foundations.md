# 基础视觉与层级

## 产品定位

面向长时间使用的生产力软件、配置工具和数据工作区。视觉表达保持安静，以信息层级、清楚的状态和明确操作帮助用户完成任务。避免用装饰动画制造“正在工作”的错觉。

## 三层结构

| 层 | 包含内容 | 材质 | 约束 |
|---|---|---|---|
| 内容层 | 列表、配置、表单、数据、聊天 | 实底 surface/canvas | 不使用 backdrop-filter；正文可选中 |
| 导航层 | 窗口标题栏、侧栏、工具栏 | 可用 chrome | 一屏可见 blur 区域最多 2 个，这是本系统性能预算 |
| 临时层 | 菜单、dialog、toast | 实底 elevated/surface | 正确处理焦点、遮罩和关闭 |

透明材质是区分导航与内容的手段。低性能或高对比模式应能回退为实底。静态 CSS 中存在多个材料类不等于运行时存在多个模糊区域，需要检查实际可见元素。

## 颜色角色

不要在业务组件直接使用“灰 900”“蓝 500”来同时表示文本和背景。使用 `ink`、`muted`、`surface`、`line`、`action`、`on-action`。状态采用 success/warning/danger，并包含文字。

蓝色是主要操作色，紫色只在输入焦点、开关、少量选择状态中出现；成功绿表示已经确认的成功。连接请求发出时只能显示“正在连接”，不能立即显示“已连接”。

## 排版

| 角色 | 默认 Web 值 | 用途 |
|---|---|---|
| 页面标题 | 28px / 1.2 / 600 | 每页一个主要标题 |
| 区域标题 | 16–20px / 1.4 / 600 | 卡片与分组 |
| 正文、控件 | 14px / 1.6 / 400–600 | 常规工作区 |
| 说明、徽标 | 12px / 1.5 | 时间、状态、补充说明 |
| 核心指标 | 32px / 1.2 / 600 | 数值和单位 |

中文与英文统一使用随包分发的 Noto Sans SC 可变黑体，缺失时回退 Microsoft YaHei UI；无需网络下载。数值启用 tabular-nums；代码用 Cascadia Code/Consolas。长段文字尽量控制在 680–760px 宽，不将全屏宽度用于连续阅读。

## 间距与形状

以 4px 为最小单位、8px 为主要节奏；主要页面内边距 24–40px，卡片内边距 24px，组间距 24–32px。小控件圆角 8–12px，内容面板 20px，dialog 24px。圆角表达组件大小，不能每个元素都使用胶囊。

## 层级检查

先去掉所有阴影和颜色，页面仍应靠标题、间距和分组表达主要任务。然后只恢复必要的主操作色。静态卡片不做悬停上浮，不给不可操作区域加 pointer。
